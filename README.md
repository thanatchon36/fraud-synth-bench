# fraud-synth-bench

Reproducible fraud-analytics research on **synthetic data only**: classic vs. modern models, under extreme imbalance, drift, label delay, and graph-structured fraud.

> **Status: work in progress.** Phase 1 (literature review) is done. See [`MISSION.md`](MISSION.md) for the full plan and [`docs/PROGRESS.md`](docs/PROGRESS.md) for current status.

- Literature review and gap analysis: [`docs/literature/REVIEW.md`](docs/literature/REVIEW.md)
- Design decisions: [`docs/DECISIONS.md`](docs/DECISIONS.md)

## Limitations

This is synthetic data. No real transactions are used anywhere in this repository, and findings may not transfer to production fraud systems.
